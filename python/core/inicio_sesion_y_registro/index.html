Inicio de sesión y registro (Core)

 

Objetivos

Crear una aplicación que requiera inicio de sesión y registro

Practicar la conexión de una aplicación Flask a una base de datos MySQL

Familiarizarse con la lógica necesaria para validar el registro de un usuario en un sitio web

Familiarizarse con la lógica necesaria para validar el inicio de sesión de un usuario en un sitio web

Generar el cierre de sesión de un usuario en una aplicación

Practicar el uso de sesiones

Es hora de juntar todo lo que hemos aprendido en esta unidad. Para esta asignación crearás una aplicación Flask que permita al usuario registrarse e iniciar sesión. Muchas aplicaciones suelen tener esta característica, por lo que es de suma importancia que aprendas cómo realizarlo.

Registro 

El usuario ingresará su información en el formulario de Registro. Los datos serán validados y en caso de tener todo correctamente lo guardamos en base de datos y regresamos un mensaje de éxito. En caso de que la información no sea válida, redirige a la página de registro y muestra el mensaje de error.

Validaciones y campos
Nombre: solo letras, al menos 2 caracteres y que no esté vacía
Apellido: solo letras, al menos 2 caracteres y que no esté vacía
E-mail: formato correcto de correo, que no exista previamente en la base de datos y que no esté vacía
Contraseña: al menos 8 caracteres y que no esté vacía
 Confirmación de contraseña: que coincida con la contraseña
Inicio de sesión

Para el inicio de sesión la validación consiste en 2 cosas:

Verificar que el correo electrónico proporcionado se encuentre asociado a un usuario de la base de datos
Verificar que la contraseña coincida con lo almacenado en la base de datos

Para saber qué usuario es el que acaba de iniciar sesión podemos almacenar esa información en sesión. Lo ideal será que creemos una variable en sesión que contenga el id del usuario. Con ese id ya tenemos todo lo necesario para obtener toda la información del usuario.

Cerrar sesión

En la página de éxito, agrega un enlace o botón para cerrar sesión. Una vez que el usuario haga click en este, debe de borrarse la sesión y por ende no permitirle entrar a la página de éxito. Solamente aquellos con sesión iniciada podrán visualizar la página de éxito.

BONUS

¡Ponte creativo con tu registro! Incluye otros tipos de campos (select, radio, checkbox, input de fecha). Valida esa información; por ejemplo, incluye la fecha de nacimiento del usuario y solamente permite que los usuarios mayores de edad puedan registrarse. Puedes crear más validaciones para tus contraseñas.

      Una forma de manejar varios botones con la misma clase es obtenerlos todos con document.querySelectorAll('.btn‑like') y luego asignarles un listener en un bucle. Cada listener puede usar this o el índice del bucle para actualizar el contador que está en otro elemento (por ejemplo, un <span> cercano).

      Pasos clave

      1. Selecciona todos los botones: const botones = document.querySelectorAll('.btn‑like');
      2. Recorre la NodeList y, para cada botón, añade onclick que busque el elemento donde mostrar el número (parentElement.querySelector('.counter')) y lo incremente.
